# apresentar
Exercício de Front-end
Página web desenvolvida como exercício prático de HTML5 e CSS3, com foco na utilização de elementos semânticos, organização de conteúdo e estilização básica.

Sobre o projeto
O projeto apresenta uma página estruturada com:

Cabeçalho;
Menu de navegação;
Seção principal;
Artigo;
Tabela de dados;
Imagens;
Rodapé.
Também foram utilizados recursos de layout com Flexbox, estilos personalizados e atributos de acessibilidade.

Tecnologias utilizadas
HTML5
CSS3
Flexbox
Estrutura do projeto
projeto/
├── exercicio.html
├── exercicio.css
└── img/
    └── logo.jpg
O arquivo HTML deve estar vinculado ao arquivo CSS por meio da tag <link>.

Funcionalidades e recursos
Estrutura semântica
Foram utilizados elementos semânticos do HTML5:

<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
Estilização
O arquivo CSS contém:

Definição de fonte;
Bordas nos elementos principais;
Organização dos itens do menu;
Efeito hover nos links;
Layout com Flexbox;
Ajuste do tamanho das imagens;
Espaçamento interno e externo.
Tabela
A página também possui uma tabela com:

Cabeçalho;
Corpo;
Rodapé;
Título;
Células mescladas.
Acessibilidade
Foram utilizados atributos aria-label para fornecer uma descrição adicional ao cabeçalho e à área que contém a tabela.
